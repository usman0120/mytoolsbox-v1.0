Which browsers support these tools?

                            
All modern browsers are supported including Chrome, Firefox, Safari, and Edge. For best performance, we recommend using the latest version of your browser.

                        

                        

                            
Are there any usage limits?

                            
These tools fetch from public APIs and datasets with no usage limits. However, very frequent requests might be temporarily rate-limited.

                        

                        

                            
How do I report issues?

                            
If you encounter any problems, please contact us through the feedback form on our homepage. Include details about the tool you were using and what went wrong.

                        

                        

                            
Is my data secure?

                            
All processing happens in your browser or through secure API calls. We don't store your input data or results on our servers.
